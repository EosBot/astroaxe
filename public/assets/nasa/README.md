# NASA/JPL planetary imagery

The planet cutouts in this directory are derived from NASA/JPL Photojournal
asset **PIA01341, “Solar System Montage (Updated)”**:

- Source: https://science.nasa.gov/photojournal/solar-system-montage-updated/
- Credit: NASA/JPL
- Missions represented: Mariner 10, Magellan, Galileo, Viking and Voyager
- Local derivative: crop, transparency mask and web-size optimization only

The original montage is retained as `solar-system-montage-pia01341.jpg` for
traceability. The UI uses a visually compressed model: planet order and orbital
motion are preserved, while sizes and distances are enlarged/compressed so the
planets remain visible on a browser viewport.

Saturn uses the isolated Voyager 2 photograph **PIA01364**, also credited to
NASA/JPL: https://science.nasa.gov/resource/saturn-taken-from-voyager-2/
