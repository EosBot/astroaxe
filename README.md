# AstroAxe — desenvolvimento

O AstroAxe ainda está em desenvolvimento e não possui uma versão promovida para produção.

O código do MVP, seu histórico e a documentação operacional estão na branch
[`develop`](https://github.com/EosBot/astroaxe/tree/develop).

A branch `main` é reservada exclusivamente para snapshots aprovados de produção. Quando uma
release for validada, sua promoção ocorrerá de `develop` para `main` pelo fluxo de revisão do
projeto.
