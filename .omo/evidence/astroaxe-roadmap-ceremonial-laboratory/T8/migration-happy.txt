prisma/migrations/20260826020000_ceremonial_corpus/ adds 15 additive tables. No existing

                                     Shem-derived schools, manuscript families...

                                     OLYMPIC | PLANETARY_INTELLIGENCE  ->  source system
  ceremonial_works / _editions       work -> edition (manuscript, printing, translation,
                                     compilation stay distinct editions)
  ceremonial_artifacts               relative path + SHA-256 + size + MIME + extraction
                                     state; absolute host paths cannot be stored
  ceremonial_locators                citable position (PAGE|FOLIO|SECTION|CHAPTER|
                                     APHORISM|PLATE|ENTRY)
  ceremonial_entities / _entity_variants
  ceremonial_media / _correspondences / _cross_references / _timing_profiles
  ceremonial_reviews                 structured approval (RIGHTS vs EDITORIAL, facet
                                     scope, reviewer, evidence locator, expiry, revocation)
  ceremonial_plans / _sessions       private practice records, encrypted-envelope columns

Identity rule enforced structurally: entities carry source_system_id and there is NO
workspace column anywhere on an entity. A workspace reaches systems only through
membership rows, so workspace identity can never substitute for source-system identity.

Claim rule enforced structurally: locator_id is NOT NULL on entity variants,
correspondences, cross-references and timing profiles, and those FKs are ON DELETE
RESTRICT — a locator cannot be removed while a claim still cites it.
