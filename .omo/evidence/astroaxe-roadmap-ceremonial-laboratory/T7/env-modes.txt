T7 — Introduce a parsed, fail-closed deployment-mode contract (2026-08-26)

## The contract

src/lib/ceremonial/mode.ts (server-only) parses CEREMONIAL_MODE through a Zod
discriminated union into ONE frozen policy object:

  { mode, servesPublicLibrary, servesLocalArchive, local: { archiveRoot, keyringFile, bind } | null }

Routes and components branch on those capabilities, never on the raw environment string,
so mode becomes behavior in exactly one place. `getCeremonialPolicy()` memoizes and
freezes it per process — mutating process.env afterwards cannot change the mode the
process is already running in. `parseCeremonialPolicy(source)` takes only an environment
record: there is no parameter through which a request, header, cookie or role could
select a mode.

src/domain/ceremonial/contracts.ts freezes the shared vocabulary Task 8 (storage) and
Task 9 (authorization) must both use: rights (PUBLIC_DOMAIN | LICENSED |
PERMISSION_GRANTED | RESTRICTED | UNKNOWN), access (PUBLIC | LOCAL_ONLY), sensitivity
(GENERAL | CULTURALLY_SENSITIVE | RESTRICTED_KNOWLEDGE) and the seven independently
authorized facets (metadata, quotation, fullText, image, seal, mediaDownload, export).
Import defaults are fail-closed: UNKNOWN rights + LOCAL_ONLY access, with metadata the
only facet an approved unknown-rights record could ever expose.

Accepted-mode cases:
- absent CEREMONIAL_MODE           -> disabled (no ceremonial surface at all)
- empty/whitespace CEREMONIAL_MODE -> disabled (treated as absent, not invalid)
- "public"                         -> servesPublicLibrary=true, servesLocalArchive=false, local=null
- "local" + archive root + keyring -> servesLocalArchive=true, bind defaults to 127.0.0.1
- explicit binds 127.0.0.1 / ::1 / localhost all accepted
- invariant asserted across every mode: servesPublicLibrary && servesLocalArchive is never true
- policy object and its nested `local` are both Object.isFrozen
